## Мелкие правки интерфейса (v0.17.2)

Два исправления вида, замеченные сразу после 0.17.1. Обновляются веб-клиент и приложение для компьютера; сервер не менялся.

- Точка непрочитанного у канала и треда стоит сразу за названием, а не у правого края строки. Счётчик упоминаний остался справа.
- В меню настроек сервера и администрирования между пунктами появился небольшой промежуток, как в настройках пользователя: выбранный пункт и пункт под курсором больше не слипаются.

## Обновление с 0.17.1

```bash
./backup.sh
# в .env: CHINCHI_VERSION=0.17.2
docker compose pull && docker compose up -d
```
