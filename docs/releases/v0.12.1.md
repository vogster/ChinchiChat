## Исправления установки и цепочка поставки (v0.12.1)

Выпуск по итогам полного ревью проекта: уязвимостей в самом приложении не найдено, исправлены две ошибки развёртывания и укреплён процесс сборки.

**Установка**

- Секреты в `.env` теперь предлагается генерировать командой `openssl rand -hex 32`. Прежняя `-base64` примерно в половине случаев давала пароль с `/`, из которого собиралась неверная строка подключения к базе, и сервер не стартовал. Если ваша установка уже работает, менять ничего не нужно; если сервер падает с `DATABASE_URL: not a valid URL`, сгенерируйте `POSTGRES_PASSWORD` заново (пароль базы меняется в контейнере `postgres` командой `ALTER USER chinchi PASSWORD '…'`) или закодируйте спецсимволы как в URL.
- Сервер доверяет ровно одному прокси перед собой (`TRUST_PROXY=1` вместо `true`). Если перед Caddy стоит ещё один прокси (CDN, балансировщик, nginx на хосте), укажите его адреса в новой переменной `TRUSTED_PROXIES` — иначе все пользователи будут видны серверу с одного адреса. Подробно — в [руководстве по установке](https://github.com/vogster/ChinchiChat/blob/main/docs/self-hosting.md#другой-прокси-перед-caddy). Для этого нужен новый `docker-compose.yml` из релиза.
- Отдельный домен для файлов (`FILES_DOMAIN`) теперь рекомендован в инструкции по установке, а не упомянут как опция.

**Сборка и зависимости**

- Образы релиза сканируются Trivy до публикации и выходят с подписанной GitHub аттестацией происхождения: `gh attestation verify oci://ghcr.io/vogster/chinchi-server:0.12.1 --owner vogster`. Образ сервера стал меньше и чище: в нём больше нет npm и corepack, а пакеты Debian обновлены при сборке. Web-образ перешёл на Caddy 2.11.
- Базовые образы (Node, Caddy, Postgres, Valkey, RustFS, LiveKit, Prometheus, Grafana) и GitHub Actions закреплены по digest и SHA; обновления приходят через Dependabot с задержкой в три дня после выхода версии.
- В CI добавлены `pnpm audit` и smoke-тест установки: стек поднимается из `env.example` и проверяется через Caddy, как при первой установке.

## Обновление с 0.12.0

```bash
./backup.sh
curl -fsSLO https://github.com/vogster/ChinchiChat/releases/download/v0.12.1/docker-compose.yml
# в .env: CHINCHI_VERSION=0.12.1 (и TRUSTED_PROXIES=, если перед Caddy есть другой прокси)
docker compose pull && docker compose up -d
```
