## Открытая бета (v0.12)

Chinchi переходит в открытый бета-тест. Всё работает каждый день, но возможны ошибки, а формат данных ещё может меняться: делайте резервные копии перед обновлением. Версия 1.0 выйдет после окончания беты и внешней проверки сквозного шифрования. Нашли ошибку — [расскажите в Issues](https://github.com/vogster/ChinchiChat/issues).

**Письма на вашем языке**

- Подтверждение email и сброс пароля приходят на языке приложения: при регистрации и после смены языка в «Настройки → Язык».
- Учётные записи, созданные раньше, по-прежнему получают письма на русском, пока язык не сменят в настройках.

**ARM-серверы**

- Образы теперь собираются и для ARM64: Chinchi можно поставить на Raspberry Pi 4/5, серверы Ampere и Graviton. Docker сам выберет нужную сборку, менять ничего не надо.

**Мониторинг**

- Готовый дашборд Grafana: подключения, запросы и время ответа API, самые медленные маршруты, время входа, события, фоновые задачи, память и CPU.
- `docker-compose.monitoring.yml` поднимает Prometheus и Grafana рядом с установкой. Grafana слушает только localhost сервера, открывается через SSH-туннель. Подробно — в [руководстве](https://github.com/vogster/ChinchiChat/wiki/Обновление-и-резервные-копии#мониторинг).

**Для участников**

- [CONTRIBUTING](https://github.com/vogster/ChinchiChat/blob/main/CONTRIBUTING.md) — как сообщить об ошибке, предложить идею или прислать код.
- [Правила сообщества](https://github.com/vogster/ChinchiChat/blob/main/CODE_OF_CONDUCT.md).

## Обновление с 0.11.x

```bash
./backup.sh
# в .env: CHINCHI_VERSION=0.12.0
docker compose pull && docker compose up -d
```

- Миграции применяются сами.
- Мониторинг — по желанию, см. выше.
