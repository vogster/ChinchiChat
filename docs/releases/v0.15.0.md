## Приложение для компьютера (v0.15)

Первый выпуск Chinchi для Windows, macOS и Linux: тот же клиент, что в браузере, в оболочке Tauri 2 — установщики лежат в этом релизе рядом с файлами сервера ([как установить и чем отличается](https://github.com/vogster/ChinchiChat/blob/main/docs/desktop.md)).

**Что умеет приложение**

- При первом запуске спрашивает адрес вашего сервера Chinchi и проверяет его; сменить сервер можно в «Настройки → Приложение».
- Системные уведомления и бейдж непрочитанного на значке в доке или панели задач.
- Трей: значок с меню «Открыть» и «Выйти»; крестик окна прячет приложение в трей (настраивается), автозапуск вместе с системой.
- Push-to-talk: глобальное сочетание клавиш, пока оно зажато, микрофон в голосовом канале включён — даже если окно не на переднем плане.
- Обновления: приложение само находит новую версию в релизах, проверяет её подпись и предлагает установить.

**Чего пока нет**

- Демонстрация экрана из приложения не работает ни на одной платформе (webview'ам нужен обработчик выбора экрана на стороне оболочки) — пользуйтесь браузером.
- Голос на Linux: WebKitGTK в Ubuntu 24.04 и 26.04 собран без WebRTC, так что голосовые каналы в приложении на Linux недоступны; текст и уведомления работают.
- Сборки не подписаны сертификатами Microsoft и Apple: при первом запуске Windows и macOS предупредят. Подпись обновлений при этом есть и проверяется.

**Сервер**

- Клиенты в bearer-режиме (приложение для компьютера, боты) больше не проходят проверку Origin ни на HTTP-запросах, ни при подключении к шлюзу: у них нет cookie, которую можно было бы подделать, а токен они предъявляют сами.

## Обновление с 0.14.x

```bash
./backup.sh
# в .env: CHINCHI_VERSION=0.15.0
docker compose pull && docker compose up -d
```

Новых переменных и нового `docker-compose.yml` не требуется.
