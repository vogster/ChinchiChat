## Шифрование: доверие проверяется, а не предполагается (v0.13)

Выпуск по итогам ревью сквозного шифрования. Протокол не менялся, беседы и ключи остаются; статус «бета» сохраняется до внешней проверки, к которой этот выпуск готовит [описание](https://github.com/vogster/ChinchiChat/blob/main/docs/encryption.md#для-независимой-проверки).

**Автор — тот, кто подписал**

- В зашифрованных беседах имя автора теперь берётся из подписи, которую проверило шифрование, а не из того, что сообщил сервер. Если они расходятся, сообщение показывается от имени подписавшего с пометкой «Подпись другого участника». Сообщение, отправленное перед самой сменой ключей беседы, помечается «отправитель не подтверждён». Наборы реакций с чужой подписью не показываются.

**Строгий режим**

- Новая настройка «Настройки → Устройства → Только подтверждённые устройства»: ваши сообщения получают только устройства, подтверждённые их владельцем, и те, что вы приняли сами после предупреждения. Остальные не читают переписку, пока вы не нажмёте «Понятно». Настройка действует в этом браузере.

**Выход стирает ключи**

- Выход из учётной записи удаляет устройство из бесед и стирает ключи и расшифрованные сообщения из браузера; то же происходит, если сеанс завершили с другого устройства. После повторного входа это новое устройство: сохраните ключ восстановления, если ещё не сделали этого.

**Подтверждение устройств и прочее**

- При подтверждении нового устройства сравниваются шесть эмодзи вместо четырёх. Устройства на старой и новой версиях покажут разные эмодзи: обновите оба перед подтверждением.
- Размер зашифрованного сообщения округляется до 256 байт, чтобы по длине нельзя было судить о содержимом.

## Обновление с 0.12.x

```bash
./backup.sh
# в .env: CHINCHI_VERSION=0.13.0
docker compose pull && docker compose up -d
```
