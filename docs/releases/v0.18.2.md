## Скачивание файлов в браузере (v0.18.2)

Исправление к 0.18.1. Обновляются веб-клиент и приложение для компьютера; в сервере изменений нет, но образ выходит с тем же номером. Миграций базы нет.

- В браузере снова открываются файлы зашифрованных бесед (картинки, файлы, голосовые), голосовые сообщения в обычных чатах и кнопка «Скачать» в просмотре картинки. В 0.18.1 браузер отбрасывал их по дороге к хранилищу, и вместо файла было «Не удалось расшифровать файл». Обычные файлы-вложения это не затрагивало.

## Обновление с 0.18.1

Приложение для компьютера предложит обновление само. Для сервера:

```bash
./backup.sh
# в .env: CHINCHI_VERSION=0.18.2 (или возьмите docker-compose.yml из релиза)
docker compose pull && docker compose up -d
```
