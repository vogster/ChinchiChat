# Как помочь Chinchi

Спасибо, что хотите помочь! Chinchi — открытый проект, и любой вклад ценен: сообщение об ошибке, идея, перевод, документация или код.

Участвуя в проекте, вы соглашаетесь с [правилами сообщества](CODE_OF_CONDUCT.md).

## Сообщить об ошибке

Создайте [issue](https://github.com/vogster/ChinchiChat/issues) и укажите:

- версию Chinchi (`CHINCHI_VERSION` или номер релиза) и браузер;
- что вы делали, что ожидали и что произошло;
- скриншот или выдержку из логов (`docker compose logs server`), **без паролей, токенов и ключей**.

**Уязвимости — только приватно:** на GitHub во вкладке **Security → Report a vulnerability**, не в публичных issue. Мы ответим и вместе решим, когда о ней можно рассказать.

## Предложить идею

Опишите в issue, какую задачу пользователя решает идея: «хочу X, чтобы Y». Посмотрите [TODO.md](TODO.md) и раздел «Идеи на потом»: возможно, она уже в планах.

## Документация и переводы

- Руководство пользователя — в [wiki](https://github.com/vogster/ChinchiChat/wiki). Нашли неточность — откройте issue или pull request.
- Строки интерфейса — в `apps/web/src/locales/ru.json` и `en.json`. Ключи в обоих файлах должны совпадать (это проверяет тест). Новый язык — новый файл и пункт в `SUPPORTED_LANGUAGES` (`apps/web/src/lib/i18n.ts`).

## Код

### Подготовка

Нужны Node.js 24+, pnpm 11 и Docker.

```bash
git clone https://github.com/vogster/ChinchiChat.git && cd ChinchiChat
pnpm install
pnpm dev:up
cp apps/server/.env.example apps/server/.env
pnpm dev                 # http://localhost:5173
```

Подробнее о структуре репозитория — в [wiki: Разработка](https://github.com/vogster/ChinchiChat/wiki/Разработка). Архитектура и принятые решения — в [PLAN.md](PLAN.md), соглашения и подводные камни — в [AGENTS.md](AGENTS.md). Прочитайте их перед заметными изменениями.

### Правила

- **Тесты сначала.** Новое поведение и исправление ошибки начинаются с теста, который падает без вашего изменения. Порог покрытия — 80%.
- **Перед коммитом** — по всему монорепо:
  ```bash
  pnpm format && pnpm lint && pnpm typecheck && pnpm test
  ```
  Для изменений интерфейса или сценариев — ещё `pnpm e2e`.
- **Коммиты** — [conventional commits](https://www.conventionalcommits.org) на английском: `feat(web): …`, `fix(server): …`, `docs: …`.
- **Язык:** код, комментарии и коммиты — на английском; документация (README, PLAN, TODO, wiki) — на русском.
- **Строки интерфейса** — только через i18n, цвета — только семантическими токенами Tailwind.
- **Зависимости** — точными версиями, без `^`. Пакеты моложе суток pnpm не поставит.
- **Безопасность:** не доверяйте вводу пользователя, проверяйте права через общие функции (`createGuildAccess`, `@chinchi/shared`), не логируйте секреты.

### Pull request

1. Сделайте форк и ветку от `main`.
2. Небольшой, сфокусированный PR проще проверить, чем большой: одна задача — один PR.
3. Опишите, что и зачем изменилось, и как вы это проверили. Для интерфейса приложите скриншот.
4. Проверки CI должны быть зелёными.

Если изменение большое (новая функция, другая архитектура), сначала обсудите его в issue: так меньше шансов, что работа пойдёт в сторону.
