## ✅ Фаза 15 — Шифрование (v0.8)

Сначала модель угроз и дизайн, потом реализация. Текстовые каналы серверов остаются шифрованными только на транспорте (TLS): там нужны поиск, модерация, боты и история для новых участников.

- [x] Модель угроз и дизайн (`docs/encryption.md`): от кого защищаем (утечка БД и бэкапов, любопытный администратор инстанса, перехват в сети), что сервер видит всегда (метаданные: кто, кому, когда), что теряется в E2EE-чатах (поиск на сервере, превью ссылок, боты, автомодерация)
- [x] Spike: библиотека MLS для браузера и React Native — выбрана ts-mls 1.6.4 (группа из 4 устройств, удаление, сохранение состояния, ключ звонка из exporter, 50 устройств за ~1 с; аудита нет — за своим интерфейсом), LiveKit E2EE — через RTCRtpScriptTransform (проверка в webview — _отложено: до фазы Desktop_)
- [x] `packages/e2ee`: обёртка над ts-mls (устройства, группы, сохранение состояния, ключ звонка) со сценарными тестами: отправитель, удаление, недоверенное устройство, гонка коммитов (откат — из сохранённой копии), подмена шифротекста (векторы RFC 9420 — _отложено: их проверяет сама ts-mls, у нас — сценарии поверх неё_)
- [x] Сервер: устройства и KeyPackage, служба доставки MLS (порядок коммитов, Welcome, зашифрованные сообщения), тип беседы «Зашифрованная беседа» (флаг `encrypted` у ЛС и групп; коммит — только для текущей эпохи, иначе `STALE_EPOCH`; Welcome — только своему устройству; сообщения — `ciphertext` без текста, без упоминаний, автомодерации и превью)
- [x] Веб: ключи устройства в IndexedDB, создание зашифрованной беседы (из карточки профиля), чтение и отправка, добавление новых и удаление отозванных устройств участников, «ждём, пока впустят это устройство»; браузер становится устройством сразу при входе; e2e — два человека в настоящем Chromium, сервер хранит только шифротекст (предупреждения о новых устройствах — _отложено: вместе с кодами безопасности_)
- [x] Одна зашифрованная беседа на пару людей: «Зашифрованная беседа» в профиле открывает уже начатую (ключ пары `e2ee:a:b` в `dm_key`, одновременные открытия — одна беседа)
